# i18n — รองรับ 4 ภาษา (ไทย / ລາວ / English / 中文)

ไม่ได้ใช้ library ภายนอก — เป็นระบบเล็ก ๆ ที่อ่านง่ายและแก้ได้เอง
ภาษาถูกเก็บใน **cookie** (`locale`) ไม่ได้อยู่ใน URL จึงไม่ต้องแตก route เป็น `/[locale]/...`

```
src/i18n/
  config.ts            # รายชื่อภาษา, ชื่อที่แสดง, locale ของ Intl, ชื่อ cookie
  dictionaries/        # ข้อความกลางของ template (core — ห้ามเพิ่มคีย์ของ module ที่นี่)
    th.ts              # ต้นฉบับ
    lo.ts en.ts zh.ts  # ต้องมีคีย์ครบเท่า th (TypeScript ฟ้องถ้าขาด)
    index.ts           # รวมข้อความกลาง + ของทุก module (deep-merge)
  modules/             # ★ ข้อความของแต่ละ module — ของ project
    define.ts          # defineModuleMessages({ th, lo, en, zh })
    index.ts           # ทะเบียน module (new:module เพิ่มให้เอง)
    products.ts        # ตัวอย่าง: 4 ภาษาในไฟล์เดียว
  translate.ts         # translateWith() + t() สำหรับโค้ดนอก React
  client.tsx           # I18nProvider + useI18n()
  server.ts            # getLocale() + getTranslations()
  actions.ts           # server action เขียน cookie
```

## ใช้งาน

**Client component**

```tsx
const { t, locale, intl, setLocale } = useI18n();

<h1>{t("products.title")}</h1>
<p>{t("products.deleteDesc", { name: product.name })}</p>
<span>{formatDate(row.updatedAt, intl)}</span>
```

**Server component**

```tsx
const { t, intl, locale } = await getTranslations();
return <PageHeader title={t("products.title")} />;
```

**นอก React** (เช่น `handleResult`)

```ts
import { t } from "@/i18n/translate";   // ใช้ dictionary ที่ I18nProvider ตั้งไว้ล่าสุด
```

## ฟอนต์ — เลือกตาม "ตัวอักษร" ไม่ใช่ตามภาษาที่เลือก

ระบบใช้ชุดฟอนต์ **ชุดเดียว** ทั้งเว็บ (`appFontStack` ใน `src/app/fonts.ts`)
เบราว์เซอร์จะไล่หาฟอนต์ใน `font-family` ทีละตัว **รายตัวอักษร** ตัวไหนไม่มี glyph ก็เลื่อนไปตัวถัดไป
ผลคือข้อความลาวที่อยู่ในหน้าภาษาไทยก็ยังเป็น Phetsarath และคำอังกฤษในหน้าลาวก็ยังเป็น Times New Roman

| ตัวอักษรที่เจอ | ฟอนต์ที่ได้ | มาจากไหน |
| --- | --- | --- |
| Latin / ตัวเลข / เครื่องหมาย | Times New Roman | ฟอนต์ในเครื่อง → สำรอง Tinos (metric ตรงกัน) |
| อักษรไทย | Sarabun | Google Fonts (next/font) |
| ອັກສອນລາວ | Phetsarath OT | ฟอนต์ในเครื่อง → ไฟล์ใน `public/fonts` → สำรอง Noto Sans Lao |
| 汉字 | Noto Sans SC | next/font → สำรองฟอนต์จีนของระบบ (Microsoft YaHei / PingFang SC) |

**ลำดับในชุดสำคัญมาก** — ฟอนต์ที่มี glyph ของอักษรไหนก่อนจะได้ใช้กับอักษรนั้น
เช่นห้ามเอา Sarabun ขึ้นก่อน Times New Roman ไม่งั้นตัวอักษรอังกฤษจะกลายเป็น Sarabun
(มีเทสต์ `tests/unit/fonts.test.ts` เช็คลำดับนี้ไว้แล้ว)

เปลี่ยนฟอนต์ของอักษรกลุ่มไหน แก้ที่ `appFontStack` ใน `src/app/fonts.ts` ที่เดียว
ถ้าต้องการให้ทุกเครื่องเห็น Phetsarath เหมือนกัน ให้วางไฟล์ woff2 ตาม `public/fonts/README.md`

## กติกา

1. **ห้ามเขียนข้อความตรงลงใน component** — ใส่คีย์ในไฟล์ของ module (`src/i18n/modules/<module>.ts`)
   ครบ 4 ภาษา ภายใต้ namespace ของ module เอง (`orders.*`) — ดู `docs/EXTENDING.md` หัวข้อ 2
2. เมนู (`config/nav.ts`) เก็บ `titleKey` / `labelKey` ไม่ใช่ข้อความ
3. ค่าคงที่ของ domain (เช่นสถานะสินค้า) เก็บเป็น map ไปหาคีย์ เช่น `statusKey.ACTIVE = "products.statusACTIVE"`
4. **zod schema** เก็บ "คีย์" ไว้ในช่อง message — `FormMessage` และ `handleResult` เป็นคนแปล
   (เพราะ server ไม่รู้ภาษาของผู้ใช้ ณ ตอน validate)
5. **server action** คืน `message` เป็นคีย์เสมอ (`errors.conflict`, `products.created`, ...)
6. วันที่/ตัวเลข/สกุลเงิน ส่ง `intl` จาก `useI18n()` เข้า `formatDate` / `formatCurrency` เสมอ
7. คีย์ที่ไม่มีในพจนานุกรมจะแสดงเป็นตัวคีย์เอง — เห็นปุ๊บรู้ทันทีว่าลืมแปล
8. **ข้อยกเว้น: title ของหน้า (แท็บเบราว์เซอร์)** เป็นภาษาอังกฤษตายตัว ไม่แปล —
   `export const metadata: Metadata = { title: "Products" };`

## เพิ่มภาษาใหม่

1. เพิ่มรหัสภาษาใน `locales`, `localeNames`, `intlLocale` (`src/i18n/config.ts`)
2. สร้าง `src/i18n/dictionaries/<code>.ts` โดย copy จาก `en.ts` แล้วแปล
3. ลงทะเบียนใน `dictionaries/index.ts` และเพิ่มภาษานั้นในทุกไฟล์ของ `src/i18n/modules/` (TypeScript จะชี้ให้ว่าขาดที่ไหน)
4. เพิ่มฟอนต์ที่รองรับภาษานั้นใน `src/app/layout.tsx` (ถ้าจำเป็น)
5. `bun test tests/unit/i18n.test.ts` — เทสต์จะเช็คให้ว่าคีย์ครบและตัวแปรในข้อความตรงกับต้นฉบับ
