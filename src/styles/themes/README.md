# Theme presets

แต่ละไฟล์คือชุดสีสำเร็จรูปที่ override ตัวแปรใน `src/app/globals.css`
วิธีใช้: เปิดบรรทัด `@import "./themes/ocean.css";` ใน `src/styles/brand.css` (ไฟล์ของ project)
(หรือ copy ค่าในไฟล์ไปใส่ `:root` / `.dark` ใน brand.css) — ห้ามแก้ `globals.css`

โครงสร้างโค้ดทั้งหมดไม่เปลี่ยน เปลี่ยนแค่ token — component ทุกตัวปรับตามอัตโนมัติ
