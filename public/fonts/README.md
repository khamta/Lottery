# public/fonts

## Phetsarath OT (ภาษาลาว)

ระบบจะใช้ฟอนต์ **Phetsarath OT** ที่ติดตั้งอยู่ในเครื่องผู้ใช้ก่อนเสมอ
ถ้าเครื่องไม่มี จะโหลดไฟล์จากโฟลเดอร์นี้ และถ้าไม่มีไฟล์อีกจะตกไปใช้ Noto Sans Lao แทน

วางไฟล์ชื่อนี้เพื่อให้ผู้ใช้ทุกเครื่องเห็นฟอนต์เดียวกัน:

```
public/fonts/Phetsarath-OT.woff2     (น้ำหนักปกติ — ไฟล์เดียวพอ)
```

ตัวหนา (font-semibold / font-bold) เบราว์เซอร์ทำให้เองจากตัวปกติ
**อย่าเพิ่ม `@font-face` ตัวหนา (700)** ถ้าไม่มีไฟล์ตัวหนาจริง — เมื่อโหลดไม่ได้
ข้อความลาวที่เป็นตัวหนาจะข้ามไปใช้ Noto Sans Lao แทน Phetsarath

แปลงจากไฟล์ .ttf/.otf เป็น .woff2 ได้ด้วย `woff2_compress` หรือเว็บแปลงฟอนต์ทั่วไป

> ฟอนต์เป็นทรัพย์สินของผู้จัดทำ — ตรวจเงื่อนไขการแจกจ่ายก่อนนำไฟล์ขึ้น repo สาธารณะ

ประกาศ `@font-face` อยู่ที่ `src/app/globals.css` และชุดฟอนต์ของแต่ละภาษาอยู่ที่ `src/app/fonts.ts`
